This section provides complete API documentation for btc_graph.

Package Structure
-----------------

btc_graph is organized into the following modules:

.. list-table::
   :widths: 25 75
   :header-rows: 1

   * - Module
     - Description
   * - ``btc_graph.io``
     - Data loading, export, and Spark session management
   * - ``btc_graph.core``
     - Graph construction and centrality computations
   * - ``btc_graph.workflows``
     - High-level analysis pipelines
   * - ``btc_graph.visualization``
     - Plotting and visualization utilities
   * - ``btc_graph.cli``
     - Command-line interface
